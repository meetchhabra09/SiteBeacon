## 🚀 How to Use

### API Endpoints
```
GET  /history              - Get history with filters
GET  /history/summary      - Get statistics
```

### Example Queries
```bash
# All history
GET /history

# Filter by name
GET /history?beaconName=GitHub

# Filter by date range
GET /history?fromDate=2024-01-01&toDate=2024-01-31

# Filter by action
GET /history?actionType=edit

# Get stats
GET /history/summary

# Combined filters
GET /history?beaconName=API&actionType=edit&fromDate=2024-01-01&page=1&limit=50
```
