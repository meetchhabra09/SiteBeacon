🎯 HOW IT WORKS
================================================================================

1. User logs in
   → Token saved to localStorage

2. Component makes API request
   → Request Interceptor adds "Authorization: Bearer {token}"

3. Backend receives request
   → Validates Bearer format
   → Verifies JWT signature
   → Checks user exists in database

4. If valid: Process request → Return 200 with data
5. If invalid: Return 401 with specific error message

6. Frontend receives response
   → Response Interceptor checks for 401
   → If 401: Clear localStorage → Redirect to login
