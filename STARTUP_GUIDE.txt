TROUBLESHOOTING
───────────────────────────────────────────────────────────────

Q: Frontend won't load
A: Make sure both servers are running

Q: "Cannot GET /"
A: Frontend server (5173) not running

Q: API errors (401, 404, 500)
A: Backend server (3001) not running

Q: Socket.io errors
A: Check backend is on port 3001

Q: Email not sent
A: Check .env has BREVO_API_KEY set
